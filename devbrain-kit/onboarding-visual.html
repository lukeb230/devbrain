Getting a teammate
onto DevBrain.

Four things have to happen: they can sign in, their Claude joins the hive mind, the widget lands on their Mac, and we prove it works. Luke does about ten minutes of admin once; each teammate does about fifteen minutes on their own machine.

The route

Seven steps, two lanes.

Black steps are Luke's (do them once, before inviting anyone). Blue steps are the teammate's — send them this doc and they can self-serve.

Lane one

Luke's prep — do once, ~10 minutes.

1

Add them to the allowlist

Vercel · ~3 min

Vercel → the DevBrain project → Settings → Environment Variables → edit DEVBRAIN_ALLOWED_LOGINS. It's a comma-separated list of GitHub usernames — add theirs exactly as it appears on GitHub:

DEVBRAIN_ALLOWED_LOGINS=lukeb230,teammate-one,teammate-two

Then Deployments → Redeploy the latest build — env changes don't apply until a redeploy. Until this is done, their sign-in is rejected by design.

2

Add them as GitHub collaborators

GitHub · ~3 min

Two repos, both under Settings → Collaborators → Add people:

lukeb230/gear-tracker — the test repo they'll actually code in.
lukeb230/devbrain-test — holds the plugin marketplace and CLI; the plugin install fails without read access.

They'll each get an email invite — remind them to accept it before step 5.

3

Share the widget app

~3 min

The widget is already built on your Mac. Zip it and send it however you like (AirDrop, Drive, Slack):

cd /Applications && zip -r ~/Desktop/DevBrain-widget.zip DevBrain.app
Alternative: teammates can build from source (the widget-shell-src-v2.zip + Rust + Node + Xcode command-line tools, ~20 min). Sharing the built app is faster and identical.
Lane two

The teammate's setup — ~15 minutes, self-serve.

Prerequisites: a GitHub account (on the allowlist), Node 18+, and Claude Code installed.

4

Sign in and mint your token

Browser · ~3 min

a. Go to https://devbrain-ebon.vercel.app → Sign in with GitHub. You'll land on the team dashboard, already inside the shared org — live presence, tasks, the brain.

b. Dashboard → Tokens (top right) → label it after your machine (e.g. maya-mbp) → Create token → copy it now. It's shown once, stored hashed, and revocable any time.

Rejected at sign-in? You're not on the allowlist yet — ping Luke (step 1).
5

Connect your machine + your Claude

Terminal + Claude Code · ~7 min

a. Clone both repos and run the connector:

git clone https://github.com/lukeb230/gear-tracker.git
git clone https://github.com/lukeb230/devbrain-test.git
node devbrain-test/cli/bin/devbrain.mjs init
# asks for: server URL (https://devbrain-ebon.vercel.app) + your token
# writes ~/.devbrain/config.json and installs the presence hooks

b. Verify the chain end to end:

cd gear-tracker && node ../devbrain-test/cli/bin/devbrain.mjs doctor
# every line should be a check mark

c. In any Claude Code session, install the plugin, then restart the session:

/plugin marketplace add lukeb230/devbrain-test
/plugin install devbrain@devbrain-marketplace
This is the hive-mind step. From now on your Claude sees teammates' live sessions, checks for collisions before every file edit, reads the team rules, task board, and brain — automatically, every session.
6

Install the widget

~3 min

a. Unzip DevBrain-widget.zip and drag DevBrain.app into Applications, then open it. The app is unsigned, so macOS will balk the first time — clear it with:

xattr -dr com.apple.quarantine /Applications/DevBrain.app

(or right-click the app → Open → Open.)

b. A brain icon appears in the menu bar (never the Dock — that's intentional). Hover your cursor into the bottom-right corner of the screen: a badge pops up; click it and the panel slides out. Sign in with GitHub inside the panel.

c. In the panel, open Settings (top right) → hit Send test notification → click Allow when macOS asks. Pick your preferred corner and "Launch at login" from the menu-bar icon's dropdown.

Known snags

The four things that actually trip people up.

GitHub 2FA inside the widget panel

If your GitHub 2FA is "GitHub Mobile only", the panel's sign-in can dead-end (no email-code option exists for 2FA accounts). Fix once: GitHub → Settings → Password and authentication → add an authenticator app — the macOS Passwords app works great. Then any TOTP code signs you in anywhere.

"App can't be opened" on first launch

That's Gatekeeper objecting to the unsigned build. The xattr -dr com.apple.quarantine command in step 6 (or right-click → Open) clears it permanently. You only do this once.

Plugin installed but tools don't answer

Two usual causes: you didn't restart the Claude Code session after installing, or devbrain init was never run so ~/.devbrain/config.json is missing. Run doctor — it names the broken link.

Invite not accepted

The git clone of a private repo fails with "repository not found" until the GitHub collaborator invite (sitting in your email) is accepted. Accept both invites before step 5.

Step seven

Prove it works — both sides check.

The teammate confirms

  • Open Claude Code in gear-tracker/ and ask "what's the team up to right now?" — it answers with live names and files
  • Ask "what should I work on next?" — it suggests from the task board with reasoning
  • Widget corner badge pops on hover; panel shows Home with to-dos and who's working
  • Test notification arrived as a native macOS banner

Luke confirms

  • New teammate appears under Now working on the dashboard while their session is open
  • Their edits show in the Activity feed with a readable label
  • Both editing the same file → the second Claude gets a collision warning before touching it
  • Their name shows up in task assignee dropdowns
