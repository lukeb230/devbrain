## What shipped after the handoff was first written (2026-09-15)

Pure cost/latency win, no quality change, billing is per-call not per-token so it's untouched. Two tests added; 369 green.
- **Brain-docs caching: considered and declined** (Luke's call). Reason: PR reviews don't send brain docs at all, and where brain docs are sent (the spec-assessment flow, `src/app/api/agents/tick/route.ts:351`) they're concatenated with volatile data (task board, merged PRs, file tree), so cross-call cache hits would be rare and a naive cache could cost more via the write premium. The one safe win — caching the corpus prefix across the spec-assessment batch loop — was offered and declined. Do not implement without Luke asking.
- **Beta cost model decided.** AI cost is per team (metered by `ai_usage.calls`), ~$0.05/action blended on Sonnet 4.5 (no caching baseline), Base cap 40 actions/day ≈ ~$60/team/month worst case. To hold the free-beta AI bill under $2,000/month: recommended `beta.max_teams` ≈ 50, per-team `ai_daily_cap` = 40, and the global backstop `system_state.ai_limits.global_daily` ≈ 1,300 (currently 5,000). These are recommendations, NOT yet applied — flip with `scripts/beta.mjs` + SQL when Luke decides. Tune from the real token sums in `ai_usage` after a week.
